# Multi-Event Format Branch

This branch is for building and testing multi-event tournament support away from the live production branch.

Initial scope:
- Multi-day or multi-week tournament setup
- Squad management
- Singles, doubles, and team event entries
- Optional all-events tracking
- Score entry by squad and event
- Public views after the admin workflow is stable

Live tournament fixes should continue on `main` and only be merged here when needed.
